# 🏢 Vrundavan Society — Modern Society Maintenance & Management Portal

A full-stack, enterprise-grade society management and community portal designed to streamline society administration, maintenance payments, incident resolution, facility bookings, and resident communications.

---

## 🌟 Key Features of Society Maintenance Portal

* 💳 **Instant Maintenance Payments**: Track outstanding dues, pay bills online, and download receipts.
* 🛠️ **Incident & Complaints Helpdesk**: Log maintenance requests with category/urgency tagging and track real-time resolution status.
* 🤖 **AI Helpdesk Assistant**: Instant automated assistance for common community queries (office hours, payment help, facility rules).
* 🏊 **Amenity & Facility Reservations**: Reserve Club House, Gymnasium, and Swimming Pool slots.
* 📢 **Digital Notice Board & Circulars**: Broadcast official circulars with automated notification alerts to all residents.
* 👥 **Resident Directory**: Verified neighbor contacts and flat directory.
* 🔐 **Security & RBAC**: Role-based access control (Admin Incharge vs Residents) and two-factor authentication (2FA).

**🛠️ Technology Stack:**
* **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons
* **Backend**: Node.js, Express.js, TypeScript, MongoDB Atlas, Mongoose, JWT, Bcrypt
* **Deployment**: Cloudflare Pages (Frontend) & Vercel (Backend)

## 💻 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/Abhijeet0848/Society-maintenance.git
cd Society-maintenance
```

### 2. Install dependencies
```bash
npm install
npm --prefix client install
npm --prefix server install
```

### 3. Run development servers
```bash
npm run dev
```
* **Frontend**: `http://localhost:5173`
* **Backend**: `http://localhost:5000`
